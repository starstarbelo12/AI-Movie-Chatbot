Movie FAQ Chatbot

User Guide for the Interactive Movie Chatbot

1. Overview

Movie FAQ Chatbot is a Streamlit application that answers natural-language questions about movies in its included dataset. It supports individual movie details, rankings, and comparisons.

2. Start the Application

Open a terminal in the project folder, create a virtual environment, and install the dependencies.

python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -c "import nltk; nltk.download('punkt'); nltk.download('punkt_tab')"
streamlit run app.py

Keep the terminal open while you use the app. Streamlit will display a local URL and usually opens it in your browser automatically.

3. Using the Chatbot

  1. Type a question in the chat box at the bottom of the page.
  2. Include a movie title for questions about a specific movie.
  3. Press Enter and read the answer in the chat history.

Tip: Ask for multiple details at once: Interstellar rating, runtime, and budget.

4. Settings

ControlWhat it does

Clear ChatRemoves the current conversation from the screen.

6. Tips and Troubleshooting

  • Use official movie titles when possible; try a shorter title or corrected spelling if a match fails.
  • For comparisons, provide at least two movie titles.
  • For rankings, include a measure such as rating, revenue, budget, popularity, runtime, or vote count.
  • Answers are limited to the included dataset.
  • If Streamlit is not recognized, activate the virtual environment and run pip install -r requirements.txt.
  • If NLTK reports missing data, rerun the NLTK download command above.
